# RedChat
чтобы запустить мессенджер, скачайте файлы и откройте командную строку или pycharm, запустите файл server.py. после запуска, откройте файл chat.html и вы увидите вход в мессенджер. нажмите кнопку зарегестрироваться и придумайте имя пользователя, которого нету и пароль, можно загрузить аватар. если после входа вам высветилось уведомления что регистрация успешна, то на странице входа войдите в свой аккаунт, введя необходимые данные, которые вы писали при регистрации. после этого у вас откроется сам чат, вы можете в текстовом поле с подписью сообщение написать сообщение и нажать кнопку отправить чтобы его отправить. также, можно посмотреть погоду в Москве, нажав кнопку погода в мск. чтобы выйти из аккаунта закройте страницу или перезагрузите ее.
